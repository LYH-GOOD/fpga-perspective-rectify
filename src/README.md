# src —— 设计源码

本目录存放本项目的全部设计源码，按实现层次划分：

| 子目录 | 内容 |
|---|---|
| `hls/` | HLS C++ 校正核：四角点检测、透视重映射 |
| `rtl/` | RTL 模块与块设计（Block Design）Tcl 脚本 |
| `ps/` | PYNQ 处理系统（PS）侧 Python 代码 |

## 约定

- 文件名只用小写英文字母、数字、下划线或连字符。
- 每个子目录内附一份说明，写明入口文件与调用关系。
- 源码与板上部署的版本必须一致；改动后重新构建，并更新 `build/` 下的报告。
