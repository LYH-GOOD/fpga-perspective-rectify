# report —— 设计报告

本目录存放提交用的设计报告与协作记录：

- **设计报告正文**：创新性、性能与资源、功能正确性
- **复现说明**：一份可供他人从零开始完整执行的操作步骤
- **大模型协作记录**：提示词、迭代过程、人工取舍的依据

## 约定

- 报告中出现的每一个数据，都必须能追溯到 `build/` 或 `board/` 下的原始记录。
- 不写未实测的数据。
- 复现说明必须细到「在哪台机器上、敲哪条命令、看到什么算成功」。
