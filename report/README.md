## 迭代与发布记录

`releases/` 是开发过程的发布记录与修改说明，按版本命名。它与上面的报告正文互补：
正文讲"为什么这么设计"，`releases/` 讲"每一版改了什么、当时是怎么判定的"。

## 约定

- 报告中出现的每一个数据，都必须能追溯到 `build/` 或 `board/` 下的原始记录。
- 不写未实测的数据。
- 复现说明必须细到「在哪台机器上、敲哪条命令、看到什么算成功」。
