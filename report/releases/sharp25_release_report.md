# 第25版：锐化即时预览

基于完整24版，保留原交接bit/HWH、remap1.5原生CPU转色路径，以及自动/AI/手动跟踪、相机复用、恢复冷却2秒和480P/600P切档进度。未合入多本书问题的修改。

## 操作与生效

锐化页取消“应用锐化”按钮与触摸区域。点击预设，在确认抬手时直接提交；滑条从按下到移动都立即更新滑条、数值和最新参数，不需额外点击。保持0..4、步长0.1。

UI只替换一个不可变的最新请求，不排队执行拖动途中的旧值。现有P1处理线程在整帧开始前取值，任意两次参数取值更新间隔至少100ms；不另起参数计时器、不等待、不限制视频帧率。即使抬手后没有新的触摸事件，下一次满足间隔的帧仍会使用最终值。一次帧内所有处理沿用同一参数快照，不在同一帧中途改锐度。

100ms是参数更新最短间隔，不是端到端显示延迟承诺。参数实际在下一次符合间隔的整帧处理开始前生效，再经过现有处理/HDMI队列显示。滑条跟手以当前实时显示刷新率为上限。

松手后异步原子保存最终选择；拖动中不写文件，画面提交回执不再触发写文件。无目标时也能保存。新一次未完成拖动不会使上一已结束手势的保存丢失；过期保存任务不能覆盖更新的已结束手势。触摸取消/离开页面会结束捕获，不额外保存未完成手势；已预览值不回滚。

分辨率仍需点“应用”切档，锐化设置不会重启相机、重找四角或请求模式切换。面板“设置值”为最新选择，“实际”为真正提交画面的有效值。现有硬件限制保留：仅单块且输出宽≤512启用PL锐化；多块/不支持尺寸明确显示旁路，无CPU锐化补偿。旁路状态下拖动不会产生锐化视觉效果。

## 帧率范围与验证

没有新增每帧图像算法、图像拷贝、相机请求或工作线程。稳定参数的帧边界读取走同一元组比较，避免读时钟和控制锁；变化期间最多10Hz更新参数和参数日志。原P1和HDMI图像通路逐字节保留。保存只在手势结束异步发生。

254项主机行为检查通过，含44项本版驱动/触摸/时间/保存/范围检查，以及切档、复用、模式策略、手动和显示连续性回归。实际1280×720合成器检查锐化等待、PL启用、分块旁路、分辨率和关面板状态；中文标签和热区核对通过。完整CPU检查链通过，包含原生边缘函数与100ms取最新值。

最初3轮主机短测合成耗时+5.93%、未改队列耗时+8.09%，存在明显测量波动，因此独立进行了9轮交替对照并保留两份原始结果：合成批量耗时+0.54%、帧中位耗时-0.67%、P90+0.74%，未改队列+0.58%。这组结果未显示稳定的大幅合成退化，但不等于无成本。记录于sharp25_validation.json；使用设备替身与转色替身，不包含实际FPGA、ARM、保存IO及连续拖动压力的板端性能。此次未连接PYNQ，实际CORR/HDMI帧率和拖动时流畅性需用户上板对照24版，不能据主机测试保证不掉帧。24版与本版硬件均为1.5，原有CPU转色成本保持。

## 上传

解压完整上传包，将程序ZIP和新安装Notebook上传到板端同一目录。停止旧程序，执行新安装Notebook全部单元；进入打印的TARGET目录，重启内核，运行p11_start.ipynb。不要覆盖24版或混用旧安装本。

先固定场景测试关闭/1.0/1.5，再连续拖动3秒、松手、关闭面板重开；重启后检查保存值。对照相同输入档位、同一目标、同一输出块数的24版CORR/HDMI帧率，提供新的run-result.log。所有24及更早报告为历史资料，以本报告为准。
