# 第15版：人工审核全量数据模型

基于第14版完整程序迭代，仅更新AI模型权重、配套校验资料与版本身份。相机采集、原生跟踪、自动/AI/手动切换、单相机/单HDMI线程、同帧成对显示、失效恢复实时原图和首次3秒/后续5秒冷却保持第14版文件内容。

数据来自PIC5、PIC6及历史数据。采用406个样本：316训练、36验证、54测试，历史物理目标分组不变。PIC5有32张照片，其中一张双书图拆为两个单目标裁剪样本；PIC6有68张。12张历史平板已重新标注物理本体边缘。

用户确认人工标注后重新生成掩膜。仅HISTORY_1055的五点标注选取四个最贴合封面角点，其余405份人工JSON逐文件哈希确认未改，坐标顺序和数值精度均保留。原1055文件另行备份。

正式训练完成80轮，最佳检查点为第79轮；每轮覆盖全部316个训练样本，并额外平衡抽取128个困难场景样本。未复用暂停前11轮临时模型，初始权重为原第14版使用的physical4模型。选择依据为验证集不退步及困难场景拟合；54张测试集未参与选择轮次。

模型仍为192×256输入、FP32、单通道分割，NCNN计算图逐字节相同，权重文件字节数相同。不增加网络层、AI调用次数、分辨率、图像复制、光流或运行队列。AI仍只给初始四角，后续沿用原手动跟踪与同目标恢复策略。

主机NCNN单线程、同8张图片交替9轮对比，纯推理中位耗时为19.62→19.49ms，推理+四角拟合为24.34→24.53ms。主机调度波动不等同于PYNQ帧率；相机与HDMI最大30FPS配置保持，板端有效CORR与DISP需同条件实测。

238项主机回归检查、8张真实Windows NCNN推理、PyTorch/NCNN导出数值对比、完整安装及CPU/启动验证配套进行。安装八图自检验证模型部署一致性，不代替上述人工标注准确率评估；ARM进程通信和实际相机/HDMI由用户板端验收。

安装：在电脑解压upload_all合集，将内层p11_rgb_v9_ai_pic56_20261028_15.zip和install_ai_pic56_full_20261028_15.ipynb一起上传到Jupyter同一目录。停止旧程序，运行安装本全部单元；自检通过后进入打印的新目录，重启内核运行p11_start.ipynb。不要覆盖旧目录或混用旧安装本。

验收请测试白布白书、反光平板、木纹背景、遮挡和连续换书，比较同条件有效CORR与DISP。绿色框和右侧结果应同帧；失效后左侧回实时原图、右侧不保留旧矫正。旧paired/overlay报告仅供版本追溯，本版依据pic56_validation.json、pic56_model_comparison.json和release_manifest.json。
