# 第14版：同帧成对显示与实时原图恢复

基于第13版完整包迭代。正常矫正时，左侧使用这次矫正任务保存的原图，绿色四角和右侧已完成矫正结果一起显示。不再在两个正常结果之间插入较新的原图和黄色参考框，解决显示时钟不同导致的绿黄交替。

明确失效、丢失或等待找角时，立即回到最新实时原图，清除旧四角和右侧旧矫正。没有新结果时，依据最近8次完成间隔设置150～250毫秒的停顿判断，初始180毫秒。只有新的已完成有效结果能刷新这个计时；原图更新、重复结果和旧代次结果不能延长等待。显示循环下一次获得调度后执行恢复，因此时限不是对板端调度延迟的硬实时承诺。

相机线程和处理线程继续独立运行，不等待左右同步。不增加AI、光流、全帧备份、图像缩放、CMA槽或排队深度。继续使用原有两组显示槽和三组矫正输出槽，旧输出仅在HDMI线程读完并提交原图后释放。模式控制、手动跟踪、恢复机制、相机、原生内核、模型和FPGA文件保持第13版内容。

恢复冷却仍为同一次连续失败首次3秒、之后全部5秒；既有稳定恢复和新目标重置、提前唤醒及AI预算保留。150～250毫秒只控制显示恢复原图，与3秒/5秒找角恢复冷却是不同的计时器。

本版取舍：正常时左图刷新率等于实际完成的矫正结果速率，并带有该任务固有的处理延迟；不会额外等待一个结果来拼对。由原图进入成对显示时，第一张完成结果可能比刚显示的预览略早，记录pair_entry_regression_ms。无法同时承诺严格同帧与左图始终为最新30FPS。失效后左侧使用独立实时原图通道，不无限冻结旧矫正等待恢复。

日志增加display_mode（PAIRED/RAW_ONLY）、pair_reason、paired_sequence、pair_timeout_ms、pair_stall_ms、pair_interarrival_ms、pair_entry_regression_ms。只有真实有效完成结果计入CORR；预览不计作有效矫正。现有自动/AI/手动来源状态继续显示。

238项主机检查通过，包括实际offer/合成器/显示线程替身、连续15FPS结果之间不插原图、停顿恢复、旧代次拒绝、100次槽位切换、手动等价、3秒/5秒恢复与取消、实际启动目录发现。四张真实Windows NCNN图片的四角漂移均为0；模型未训练。新CPU自检继续执行原有原生跟踪检查，并检查成对显示计时。

主机9轮交替对比：快照发布/几何元数据中位耗时约272→232微秒，同画面合成约2993→2802微秒，详见paired_benchmark.json。基准包含CPU颜色转换与HDMI替身，有主机调度波动；不能推算PYNQ帧率。相机/HDMI最大帧率设置仍为30FPS。有效矫正处理路径未增加图像工作，板端实际CORR/DISP仍需同条件验收。

安装：在电脑上解压upload_all合集，将内层程序ZIP与install_ai_paired_full_20261028_14.ipynb一起上传Jupyter同一目录。停止旧程序，运行安装本全部单元；四图AI与CPU自检通过后进入打印的新目录，重启内核，运行p11_start.ipynb。使用本版匹配安装本；旧目录保留。完整包内包含模型、ARM NCNN和原FPGA文件。

验收：同背景、光线和目标比较CORR(valid)；正常静止/移动时检查绿色框与右侧同帧、无黄色参考切换；遮挡、移出、换书时左侧持续更新且不保留旧右图；处理停顿后观察RAW_ONLY/pair_stall；恢复后新结果直接成对显示。继续检查连续失败的retry_s为3、5、5。手动、截图和只显示矫正布局保留既有使用方式。
