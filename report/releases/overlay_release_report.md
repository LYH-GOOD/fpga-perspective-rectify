# 第13版：独立四角框与恢复冷却3秒/5秒

基于第12版安装修复1完整包迭代。模型未训练，FPGA、原生跟踪内核、自动与手动前端、P1执行、相机采集及准备队列保持原文件内容。

此前框闪烁的原因：实时左图领先右侧矫正结果时，显示代码因帧号不同清空四角。第13版在准备线程取得有效几何结果后，发布独立四角元数据；显示框不再等待对应矫正像素完成。原始“消失、出现、消失”复现现在3次均能显示有效四角。

绿色框对应当前原图帧已验证的四角。原图稍新、仍为同目标且运动稳定时，可显示黄色短时参考框，原图与几何时间差最多150毫秒；短时软失败最多缓冲120毫秒。新目标、确认空场景、明显大运动/前后向核验失败或持续失效清除参考框。旧代次和未来帧几何不会覆盖当前原图。

参考框仅用于显示，不参与矫正、AI回退、目标有效判断或有效矫正FPS统计。右侧原有失效清除规则、左侧持续实时输出及单相机消费者/单HDMI输出线程保持不变。只有最近两组四角元数据，没有增加原图备份、AI调用、光流或缩放。

恢复冷却改为同一次连续失败过程首次3秒、之后统一5秒，取消10秒/20秒递增。新目标与持续恢复成功仍按既有策略重置；已有稳定新候选提前唤醒规则保留。两次快速恢复轮次、自动找角时限、AI执行时间及每分钟自动AI预算不变，因此冷却长度不等于两次AI调用之间的总间隔。

日志新增overlay_drawn、overlay_kind、overlay_reason、overlay_source_sequence、overlay_age_ms、overlay_epoch，可区分真正丢失、参考框与显示不同步。输入/矫正结果帧号仍分别记录，不能把异步画面标成同帧。

247项主机检查通过，含28项几何/实际合成器检查、42项恢复控制器测试（3秒/5秒触发边界与稳定重置）、真实输出槽/采集/HDMI循环替身、实际手动跟踪等价及原生跟踪回归。四张记录图片完成Windows原生NCNN推理，四角与预期一致。实际ARM IPC、相机/HDMI和帧率由用户板端验收。

健康路径配对主机基准记录在overlay_benchmark.json：比较第12版与第13版相同可见四角时的快照发布/几何和合成开销。主机使用CPU颜色转换及HDMI替身，不等同于PYNQ FPS。原相机与HDMI最大帧率配置仍为30FPS，不承诺未经板端测试的帧率不降。

安装时，在电脑上解压upload_all合集，把内层程序ZIP与匹配的install_ai_overlay_full_20261028_13.ipynb一起上传Jupyter。停止旧程序，运行安装本全部单元，四图AI与CPU自检通过后进入打印的新目录，重启内核运行p11_start.ipynb。旧目录保留；自检/AI清单版本修复和完整哈希检查已保留。

验收请使用同一目标、光线、背景与比较布局：检查静止框持续可见、正常移动后能跟随、短暂遮挡显示有期限的参考框、换书不留旧框；右侧失效清除且左侧不停。比较有效CORR与DISP，另测连续失败的冷却日志retry_s依次为3、5、5、5。大运动或真实丢失时仍允许清框，避免把错误四角画到新目标上。
