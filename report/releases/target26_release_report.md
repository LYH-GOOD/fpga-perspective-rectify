# 第26版：AI后可点选切书，实时重选

基于第25版完整上传程序迭代，保留交接bit/HWH（remap1.5）、原生CPU转色、模型权重、真正手动跟踪器、相机复用和锐化即时预览。

## 已修改

1. 同时修复UI入口与显示源权限。AI找到四角后虽然复用手动跟踪，也能点击左侧实时图选别的书。真正手动编辑仍保持原交互。
2. 依照当前显示矩形和实际源图尺寸换算点击：600P的800×600源图缩成640×480时，坐标正确反算；拒绝边栏。480P仍兼容。
3. 点击有独立请求ID与源帧。普通入口仍先AUTO，转AI仍保留此次点选；手点AI且尚未失去目标时保留其AI锁。对移动后的点击用现有小图局部特征作一次源到当前映射，无法可靠映射就结束此次点选，不盲用旧坐标。
4. 复用同一次AI返回的192×256掩膜，分别拟合各有效连通组件，选择点击落入的那一本，精修也仅使用该组件。未点选且明确多本时提示点选。小于已有2%掩膜面积门槛的目标仍不额外放宽。
5. 对细桥连接做一次小图分离；只有点击对应的分块经原有物理边缘校验、与该分块重合且覆盖点击，才接收。分不清提示“目标未分清，请点书中心或拉开两本书”。未增加ROI推理：当前没有可信目标ROI可安全复用，失败时不会盲裁切重试。
6. 新目标属于当前请求、来自点中单本候选、通过原有当前帧对齐/准入，并且CURRENT结果真实提交后，才报告切换完成。仅“大框包含点击”不算选对；没有单本来源证据的旧大框不能拦住重选。第二次点击替代第一次，旧请求不能覆盖新请求。
7. 去掉切书专用的整屏冻结事务。点击即提交，等待期间复用当前相机实时预览；旧会话退出后左图继续当前画面，新矫正结果准备好后走原显示owner提交。没有额外相机、常驻第二跟踪器或全屏暂存。点选失败结束该请求，等待新点选或真实离开后返回，避免同次点击无限AUTO/AI循环。
8. 删除锐化数值后的“待矫正输出”、分块/尺寸旁路文字。设置值、实际值和诊断日志保留；硬件旁路限制仍有效。100ms帧边界取最新值、松手异步保存和取消锐化应用按钮均沿用25版。

## 保持的规则

丢失确认1.2秒；AUTO无候选1.5秒；已有候选验证总上限2.8秒；短暂延续最多1秒，使用旧可信四角矫正当前相机画面；恢复冷却2秒；AI稳定成功3秒退还本次额度，失败限制保留。普通AUTO阈值不变。确认失去已找到目标后仍按原策略回AUTO；手点AI只在尚未找到前保持AI，不改成永久锁定。

普通自动成功仍复用原自动跟踪；AI成功仍复用原手动跟踪。未训练、未换bit、未改锐化驱动、未增加正常帧中的多目标检测。主机逐字节检查模型/相机/原生像素/手动跟踪/自动跟踪核心，AST检查正常HDMI_show与P1_execute保持一致。新开销主要在点击、点选候选与一次AI返回；输出元数据携带紧凑请求证明，不携带大图。
