# 人工复核标注与困难样本增量训练

适用：书本与平板物理外缘分割数据。用法：冻结原图及原始JSON，按同一四角顺序与物理外缘定义预标注，交给用户复核，明确确认后才训练。多点标注必须按当前授权处理：只许可修正某一张五点图时，不得扩展为全库自动改角。对于歧义、遮挡和不可见角，保留记录供人工选择，不把内屏边缘混入机身外缘。

来源：PIC7、PIC8等困难场景人工复核与增量训练。已验证：第29版训练报告记录469张合并数据，379训练、36验证、54测试，80轮；历史验证和测试通过数未退步。PIC7/8进入训练组，其拟合改善不是独立泛化证明。本包不附训练原图或宣称可一键复现训练，使用者应自备授权数据及训练工程。

边界：相近视频帧需按拍摄组防止泄漏；不能以训练集高通过率替代新背景验证。训练权重的精度改进与板端推理时延分开测量，模型结构不变也不代表系统FPS必然不变。
