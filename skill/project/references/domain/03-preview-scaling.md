# 03 · 预览缩放：源图放不进显示槽时怎么办

> 领域层（题型绑定：把某个摄像头的画面对准某个显示分区）。
> 通用方法论请见 `../../references/generic/07-measurement-discipline.md` §十。

## 一、这个问题什么时候出现

"左边原图 / 右边校正图"的并排布局里，原图那一格是**固定尺寸**（本例 640×480）。
摄像头一旦换到更大的分辨率（本例 800×600），就放不进去，必须每帧缩放。

**关键是非对称**：小分辨率 **1:1 不缩放**，大分辨率**每帧都要缩放**。
两者在同一次运行里的开销差 **7 倍**，而这一点在功能上完全看不出来。

本例实测（同一份日志内对比）：

| 输入 | 后端 | 转换耗时（中位）| 显示线程合成 |
|---|---|---:|---:|
| 640×480 | 1:1 | **10.8 ms** | 26.1 ms |
| 800×600 | 双线性多相 5:4 | **77.2 ms** | 107.8 ms |

## 二、先做对照，再决定改哪里

不要一上来就优化缩放算法。先做一个**"完全不缩放"的对照组**：

| 后端 | 转换 | 合成 | 显示 fps | 代价 |
|---|---:|---:|---:|---|
| 双线性多相 5:4（原）| 77.2 ms | 107.8 ms | 10.0 | 无 |
| 通用标量最近邻 | 87.4 ms | 115.4 ms | 8.0 | 无 |
| **居中裁剪 1:1（对照组）** | **19.0 ms** | **37.4 ms** | **15.5** | **掉左右各 20% 视野** |
| 不画原图 | 0 | 12.1 ms | 14.0 | 只有校正图 |

**对照组的价值**：它证明了 **77 ms 里有 58 ms 是缩放本身的开销**，
而不是合成、不是叠加层、不是 DMA。没有这个对照组，很容易去改错地方。

缺点是裁剪丢视野，不可交付 ⇒ 只能作为"上限参照"。

## 三、正解：把整数比例展开成定数模式

5:4 缩放的映射是**固定不变的**：

```
输出 4 个像素  ↔  源里连续 4 个像素   =  12 字节
组间步进 5 个源像素                   =  15 字节
```

所以内层不需要任何除法或查表，**直接 memcpy**：

```cpp
for (; x + 4 <= dw; x += 4)
    memcpy(dst + 3*x, src + (x/4)*15, 12);   // 12 字节 = 4 个像素 × 3 通道
```

源行同理：**行索引表早就被算好并缓存了**（本例 `axis()` 产出的 `y0[]`），直接查表即可。

**⚠️ 反例（我踩过）：第一版写成了**

```cpp
const int i = int((long long)x * sw / dw);   // 每个输出像素一次 64 位除法
```

307k 次 64 位除法在 Cortex-A9 上**比原实现还慢 49%**。
而且 **x86 主机上测不出来**（x86 有硬件 64 位除法，只慢 14%）。
详见通用层 `07` §10.4。

## 四、结果

| 指标（800×600 预览）| 改前 | 改后 |
|---|---:|---:|
| 转换耗时 | 77.2 ms | **17.6 ms（−77%）** |
| 显示合成 | 107.8 ms | **36.4 ms** |
| 显示帧率（中位 / p90）| 10.0 / 13.5 fps | **15.5 / 16.0 fps** |
| 处理帧率 | 15.94 fps | **16.46 fps**（相机上限 16.67）|
| 有效视野 | 100% | **100%** |

代价与"居中裁剪"持平（17.6 vs 19.0 ms），但**视野零损失**。

## 五、适用范围与失效条件

- ✅ 适用于**任何整数比例**的缩放（5:4、4:3、2:1……）：找到"输出几个像素对应源里连续几个像素"，
  内层就能退化成 `memcpy`
- ⚠️ **非整数比例**（如 800→720）不成立，需要查表 + 最近邻或双线性
- ⚠️ 最近邻在 **< 1 的缩放比**下会有锯齿；预览可接受，**成品图**要评估
- ⚠️ 只在**预览**路径上用：校正输出走的是完全不同的链路，不要一起改

## 六、验证方式

- **正确性**：按同样的最近邻规则重建一张目标尺寸的源图，走 1:1 通路，
  与直接缩放的结果**逐像素比对**（本例 max diff = 0，100% 相等）
- **性能**：板上日志里看转换耗时与显示帧率两个字段，**不看主机测速**
