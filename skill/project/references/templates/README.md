# 案例模板：可直接套用的脚本与骨架

> 竞赛技能包允许"案例模板：可被下一个题目直接套用的工程骨架、脚本模板、报告模板"。
>
> **本目录不复制代码，只做索引** —— 模板都在本仓库里**实际跑通过**的位置，
> 避免"技能包里放一份、仓库里一份，然后两边不同步"（这是本项目踩过的坑，见坑 47/48）。
>
> **失效条件**：非 PYNQ / 非 Zynq 的项目，寄存器地址和板卡预设需要改。

## 二、⭐ 最值得搬的一个思路：**黄金模型 + 双参考判据**

这不是脚本，是**流程骨架**，但对任何"硬件实现一个已知算法"的题目都适用。

```
        ┌─────────────────────────────────────┐
        │  黄金参考（Python，逐位复刻 RTL）      │  ← 判据：必须逐字节一致
        └─────────────────────────────────────┘
                    ↕ 比对
        ┌─────────────────────────────────────┐
        │  待测：RTL 仿真 / 上板输出            │
        └─────────────────────────────────────┘
                    ↕ 比对
        ┌─────────────────────────────────────┐
        │  效果参考（浮点/OpenCV）              │  ← 参考：只看趋势
        └─────────────────────────────────────┘
```

**三条落地要点**（本项目实测有效）：

1. **黄金模型必须"逐位"**：同样的整数位宽、同样的截断方式、同样的舍入。
   浮点模型当判据会让真 bug 淹没在固有误差里（见 `../generic/05-verification-method.md`）。

2. **两侧兜住**：`RTL 仿真` 保证"逻辑对"，`上板输出` 保证"硬件对"。
   本项目两个 bug 分别只在前者/后者暴露。

3. **上板也要比对**：把黄金模型**拷到板子上**，让脚本自己判 PASS/FAIL，
   而不是人眼看图。板子上的判据和后端用同一个模型。

> **怎么算"逐位复刻"**：拿 RTL 的算法用 Python 重写一遍，
> 每一个 `>>`、每一个 `&`、每一个截断都照抄。
> 本项目这份模型 ~60 行，**已经和真实 RTL 仿真逐字节验证过**。

## 三、可复用的"检查脚本"清单

| 检查 | 脚本 | 检查什么 |
|---|---|---|
| 目录布局自适应 | `sim/run_sim.sh`、`sim/run_board_cfg.sh` | 换环境不会路径报错 |
| **上板前尺寸/约束自检** | `src/ps/find_homography.py::check_pl_limits()` | 尺寸超限、字节数不整除等（**别让用户从花屏反推**）|
| **行缓存需求预检** | `src/ps/find_homography.py::required_line_rows()` | 上板前算出所需深度，超了给对策（**防演示时冻结**）|
| **BD 地址自查** | `build/create_bd.tcl` 末尾 | `validate_bd_design` 返回 0 也可能有从机悬空 |
| **notebook 语法自检** | `build/make_notebook.py` 末尾 | 生成的 `.ipynb` 每个 code 格 `ast.parse` |
| **多次运行一致性自检** | `board/pynq/rectify_board.py` | 同样输入跑两次必须逐字节相同（抓"状态没清干净"）|
| **DMA 超时保护** | 同上 | `wait()` 无超时，改成带超时并**打印现场** |

## 五、搬用时**必须改**的地方

| 项 | 在哪 | 为什么 |
|---|---|---|
| **寄存器基地址** | PS 脚本里的 `REG_BASE` | BD 地址分配变了就对不上（查 `.hwh`）|
| **板卡预设** | `create_project.tcl` 的 `board_part` | 换板必须改，否则 PS7 用不了官方预设 |
| **part 型号** | 同上 | 换芯片必改 |
| **DMA 长度位宽** | `create_bd.tcl` 的 `c_sg_length_width` | 按**你的图像字节数**算够不够 |
| **行缓存深度的"跨度约束"** | RTL 参数 `ROWS` | 见 `../domain/01-streaming-image-remap.md` |
| **相机焦距** | `find_homography.py::CAL_F_RATIO` | **换相机必重标**（见 `../domain/02-single-view-geometry.md`）|
