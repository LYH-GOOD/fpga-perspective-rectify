# sim —— 仿真与验证

本目录存放不依赖硬件的验证材料，分两类。

## checks/ —— 能跑的检查（26 个）

`*_cpu_check.py`、`*_board_check.py`、基准脚本。每个都是独立可执行的主机侧检查，
覆盖对应版本的回归项：几何、跟踪、显示、恢复、界面、AI 协议。

跑法：

```
python sim/checks/<名字>.py
```

## results/ —— 检查的原始输出（66 个）

`*_validation.json`、`*_benchmark.json`、`*_review.json`、运行日志。
保留原始输出，不截断、不改写。

## 约定

- **每个检查必须能判红**：先故意制造一次失败，确认它会报错，再相信它的通过结果。
  一个从未失败过的检查，等于没有检查。
- 仿真结果与板上实测数据分开存放，不混算、不互相外推。
- `results/` 里的数据是历史版本的证据链，**不要覆盖**；新结果另起文件名。
