# board —— 上板运行

本目录存放板上部署与实测材料：

- PYNQ overlay（`.bit` + 同名 `.hwh`）
- 板上运行的 Jupyter Notebook 与 Python 脚本
- 实测输出：帧率、耗时分解、运行日志

## 环境

| 项 | 版本 |
|---|---|
| 开发板 | PYNQ-Z2（`xc7z020clg400-1`） |
| 板上镜像 | PYNQ v3.1（pynq 3.1.1 / Python 3.10.4） |

## 约定

- `.hwh` 必须是 XML 格式，且与 `.bit` 同名、同目录，否则 `Overlay()` 找不到硬件信息。
- 板上实测数据必须注明采集条件（分辨率、相机、光照），不得与其他配置的数据混算。
- 跨版本比较帧率只采用同一口径，并写明口径定义。
