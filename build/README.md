# build —— 可复现构建

本目录存放从源码到比特流的完整构建链：

- 构建脚本：Vivado / Vitis 批处理 Tcl、HLS 编译配置 `hls_config.cfg`
- 综合与实现报告：时序、资源占用、功耗
- 版本记录：每次构建对应的源码指纹与产物指纹

## 约定

- 构建脚本必须能从零跑通，不依赖任何手工点击。
- 报告保留原始输出，不截断、不做摘要。
- ⛔ 不提交 Vivado 构建产物（`.runs/` `.cache/` `.hw/` 等），已在 `.gitignore` 中排除。
